まず `.claude/rules/loop-policy.md` を読み、それに従うこと。

## この周でやること

以下を上から順に確認し、**最初に該当したものだけ**を実行する。

1. 現在のブランチに PR があり、CI が失敗しているかレビューコメントが付いていれば、それに対応する
2. `.claude/state/loop.md` の「対応中」に issue が載っていれば、`/implement-issue` でその続きをやる
3. どちらも無ければ `/loop-triage` を実行する
   - 着手候補が挙がり契約検査に合格したら、続けて `/implement-issue #NN` を実行する
   - 着手候補が無ければ「異常なし」と1行だけ報告して終わる

## 守ること

- **1周につき1 issue。** PR を作ったらこの周は終了する
- **新しい取り組みを勝手に始めない。** issue に無いことはやらない
- **ラベルを自分で付け替えない。** 提案のコメントを書くだけ
- 停止条件に当たったら、作業があれば draft PR を出して止まる。作業が無ければ issue にコメントして止まる
- 終了時に `.claude/state/loop.md` を必ず更新する

## 報告

5行以内。長い経過説明は書かない。
