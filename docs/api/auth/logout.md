# DELETE /v1/auth/logout

## 概要

Cookie のリフレッシュトークンを検証してログアウトする。冪等性あり。

## リクエスト

### 認証

`Cookie: refresh_token=<リフレッシュトークン>`

## 処理詳細

1. Cookie のリフレッシュトークンを検証してログインユーザーを特定
2. 一致する `refresh_tokens` レコードを削除
3. Cookie を破棄して返す
4. Cookie がない / レコードが存在しない場合は 200（ログアウト済み）を返す

## レスポンス

### 成功

```json
// 200 OK（正常ログアウト）
{
  "message": "ログアウトしました。"
}
```

```json
// 200 OK（ログアウト済み）
{
  "message": "すでにログアウト済みです。"
}
```
