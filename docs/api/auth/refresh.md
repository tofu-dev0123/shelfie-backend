# POST /v1/auth/refresh

## 概要

HttpOnly Cookie のリフレッシュトークンを検証し、新しいアクセストークンを発行する。

## リクエスト

### 認証

`Cookie: refresh_token=<リフレッシュトークン>`

Cookie は既存実装と同じ設定に準拠する（`httponly: true, secure: true, same_site: :lax`）。

## 処理詳細

1. Cookie からリフレッシュトークンを取得
2. `refresh_tokens` テーブルでトークンの存在・有効期限を検証
3. リフレッシュトークンの残り有効期限に応じて処理を分岐する（スライディングウィンドウ方式）
   - 残り有効期限 **> 15日**: 新しいアクセストークン（60分）のみ発行して返す
   - 残り有効期限 **≦ 15日**: 新しいアクセストークン（60分）を発行して返す。あわせてリフレッシュトークンを再発行し（30日）、DBを更新して Cookie をセットし直す

## レスポンス

### 成功

```json
// 200 OK
{
  "access_token": "eyJ..."
}
```

### エラー

| code | ステータス | 場面 |
|---|---|---|
| `UNAUTHORIZED` | 401 | Cookie なし・リフレッシュトークンが無効・期限切れ・DB に存在しない |
