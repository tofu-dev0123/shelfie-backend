# POST /v1/me/follows/:username

## 概要

指定したユーザーをフォローする。

## リクエスト

### 認証

`Authorization: Bearer <アクセストークン>`

### パスパラメータ

| パラメータ | 型 | 説明 |
|---|---|---|
| `:username` | string | フォローするユーザーの username |

## 処理詳細

1. アクセストークンを検証してログインユーザーを特定
2. `:username` でフォロー対象の User レコードを検索
3. 自分自身へのフォローでないか確認
4. 既にフォロー済みでないか確認
5. `follows` レコードを作成

## レスポンス

### 成功

```json
// 201 Created
{
  "message": "フォローしました"
}
```

### エラー

| code | ステータス | 場面 |
|---|---|---|
| `UNAUTHORIZED` | 401 | アクセストークンが無効・期限切れ |
| `NOT_FOUND` | 404 | ユーザーが存在しない |
| `CONFLICT` | 409 | 既にフォロー済み |
| `VALIDATION_ERROR` | 422 | 自分自身をフォローしようとした |
