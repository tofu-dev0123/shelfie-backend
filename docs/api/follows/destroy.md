# DELETE /v1/me/follows/:username

## 概要

指定したユーザーのフォローを解除する。冪等性あり（ユーザーが存在しない場合・フォローしていない場合も 200 を返す）。

## リクエスト

### 認証

`Authorization: Bearer <アクセストークン>`

### パスパラメータ

| パラメータ | 型 | 説明 |
|---|---|---|
| `:username` | string | フォロー解除するユーザーの username |

## 処理詳細

1. アクセストークンを検証してログインユーザーを特定
2. 自分自身のusernameでないか確認
3. `:username` でフォロー対象の User レコードを検索（存在しない場合も 200 を返す）
4. `follows` レコードを検索・削除（存在しない場合も 200 を返す）

## レスポンス

### 成功

```json
// 200 OK
{
  "message": "フォローを解除しました"
}
```

### エラー

| code | ステータス | 場面 |
|---|---|---|
| `UNAUTHORIZED` | 401 | アクセストークンが無効・期限切れ |
| `VALIDATION_ERROR` | 422 | 自分自身のフォローを解除しようとした |
