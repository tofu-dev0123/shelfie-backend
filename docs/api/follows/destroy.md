# DELETE /v1/me/follows/:username

## 概要

指定したユーザーのフォローを解除する。

## リクエスト

### 認証

`Authorization: Bearer <アクセストークン>`

### パスパラメータ

| パラメータ | 型 | 説明 |
|---|---|---|
| `:username` | string | フォロー解除するユーザーの username |

## 処理詳細

1. アクセストークンを検証してログインユーザーを特定
2. `:username` でフォロー対象の User レコードを検索
3. `follows` レコードを検索・削除

## レスポンス

### 成功

```json
// 200 OK
{
  "message": "フォローを解除しました"
}
```

### エラー

| code | ステータス | 場面 |
|---|---|---|
| `UNAUTHORIZED` | 401 | アクセストークンが無効・期限切れ |
| `NOT_FOUND` | 404 | ユーザーが存在しない・フォローしていない |
