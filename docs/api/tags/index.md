# GET /v1/tags

## 概要

タグ一覧を取得する。本棚投稿時のタグ入力オートコンプリートに使用する。
タグはシードデータで管理されるため、全件返してクライアント側でフィルタリングする。

## リクエスト

### 認証

不要

### クエリパラメータ

なし

## 処理詳細

1. 全タグをタグ名の昇順で返す

## レスポンス

### 成功

```json
// 200 OK
// Cache-Control: public, max-age=86400
{
  "tags": [
    { "name": "Go" },
    { "name": "GraphQL" }
  ]
}
```
