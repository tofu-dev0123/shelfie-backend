# GET /v1/tags

## 概要

タグサジェストAPI。本棚投稿の `content` 入力中に `#` のあとに続く文字列でサジェストを表示する用途。
`q` に部分一致するタグを、前方一致優先で最大 10 件返す。

## リクエスト

### 認証

不要

### クエリパラメータ

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| `q` | string | 必須 | 検索クエリ。1〜50文字 |

## 処理詳細

1. `q` のバリデーション（未指定・50文字超は 422）
2. `name ILIKE '%q%'` で部分一致検索（大文字小文字無視）
3. 前方一致（`name ILIKE 'q%'`）を優先し、それ以外は `name` 昇順で並べる
4. 上位 10 件を返す

## レスポンス

### 成功

```json
// 200 OK
{
  "tags": [
    { "name": "Ruby" },
    { "name": "Rust" }
  ]
}
```

### エラー

| code | ステータス | 場面 |
|---|---|---|
| `VALIDATION_ERROR` | 422 | `q` 未指定、または 50 文字超 |
