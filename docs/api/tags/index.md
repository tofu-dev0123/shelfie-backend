# GET /v1/tags

## 概要

タグ一覧を取得する。本棚投稿時のタグ入力オートコンプリートに使用する。

## リクエスト

### 認証

不要

### クエリパラメータ

| パラメータ | 型 | 必須 | デフォルト | 説明 |
|---|---|---|---|---|
| `q` | string | 任意 | なし | タグ名の前方一致検索 |

## 処理詳細

1. `q` がある場合は前方一致でタグを検索
2. `q` がない場合は全タグを返す
3. タグ名の昇順で返す

## レスポンス

### 成功

```json
// 200 OK
{
  "tags": [
    { "name": "Go" },
    { "name": "GraphQL" }
  ]
}
```
