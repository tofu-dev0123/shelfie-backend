# GET /v1/users/username/check

## 概要

username の重複チェックを行う。サインアップ時にデバウンスで呼び出される。

> **注記:** レートリミットはインフラ層で対応予定。フロント側でデバウンス処理を実施すること。

## リクエスト

### 認証

不要

### クエリパラメータ

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| `value` | string | 必須 | チェックする username（3〜40文字、小文字英数字と _ のみ、連続する _ は不可） |

## 処理詳細

1. `value` のバリデーション（形式チェック）
   - 使用可能文字: 小文字英数字 (`a-z`, `0-9`) と `_`
   - 長さ: 3〜40文字
   - 連続した `__` は禁止
   - 先頭・末尾の `_` は許可
2. `users` テーブルで `username` の存在チェック
3. 結果を返す

## レスポンス

### 成功

```json
// 200 OK
{
  "available": true
}
```

```json
// 200 OK
{
  "available": false
}
```

### エラー

| code | ステータス | 場面 |
|---|---|---|
| `BAD_REQUEST` | 400 | `value` パラメータがない |
| `VALIDATION_ERROR` | 422 | `value` が形式不正（文字種・長さ・連続アンスコ・大文字） |
