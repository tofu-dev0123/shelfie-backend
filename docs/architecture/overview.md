# システム概要

## プロダクト概要

Shelfie は、エンジニア向けの書籍管理 Web アプリケーションです。
ユーザーは読了した技術書を本棚として登録・公開し、他のエンジニアの本棚を閲覧することで新しい書籍と出会うことができます。

### コアバリュー

「自分が読んだ本を読んだ人が、他に何を読んでいるか」を軸にした書籍の発見体験を提供します。
SNS 的な気軽さで読了記録を投稿・管理でき、エンジニアの学習文化を支援することを目的としています。

## 技術スタック

| レイヤー | 技術 | 採用理由 |
|---|---|---|
| Frontend | Next.js | SSR/SSG による高いパフォーマンス、React エコシステム |
| 状態管理 | Zustand | 軽量・シンプルな API、Context の代替として学習目的も兼ねる |
| Backend | Ruby on Rails (API mode) | 新規言語・フレームワークへの挑戦、高い開発生産性 |
| Database | PostgreSQL | Rails との親和性、信頼性の高いリレーショナル DB |
| 認証 | Google OAuth 2.0 | ログイン UX の簡素化、パスワード管理を不要にする |
| 外部 API | Google Books API | 書籍メタデータ（タイトル・著者・表紙画像等）の取得 |
| デプロイ | PaaS（未定） | 個人開発における運用コストの最小化 |
| CI/CD | GitHub Actions | 自動テスト・デプロイパイプラインの構築 |

## コアデータモデル

```
┌──────────┐       ┌─────────────┐       ┌──────────┐
│  Users   │       │  UserBooks  │       │  Books   │
├──────────┤       ├─────────────┤       ├──────────┤
│ id       │──────<│ user_id     │>──────│ id       │
│ name     │       │ book_id     │       │ title    │
│ email    │       │ status      │       │ authors  │
│ avatar   │       │ content     │       │ isbn     │
│ bio      │       │ created_at  │       │ thumbnail│
└──────────┘       └─────────────┘       │ google_  │
                                         │ books_id │
                                         └──────────┘
```

- `Books` テーブルは Google Books API から取得したデータをキャッシュします
- `UserBooks` がユーザーの「本棚エントリ」であり、読了ステータスや投稿本文（`content`）を保持します
- 同一書籍の `UserBooks` を集計することで「この本を読んだユーザー」を特定します

## 主要なデータフロー

### 書籍登録フロー

```
ユーザー
  │
  ├─ 書籍タイトル/ISBN で検索
  │       │
  │       ▼
  │   Google Books API にリクエスト
  │       │
  │       ▼
  │   Rails が結果を返却（DBには未保存）
  │       │
  ├─ 書籍を選択・ステータス・レビューを入力
  │       │
  │       ▼
  │   Rails が Books テーブルに保存（未登録の場合）
  │       │
  │       ▼
  │   UserBooks テーブルに本棚エントリを作成
  │       │
  └─ 本棚に追加完了
```

### 書籍発見フロー

```
ユーザー
  │
  ├─ 書籍詳細ページを閲覧
  │       │
  │       ▼
  │   「この本を読んだユーザー」一覧を表示
  │       │
  ├─ 気になるユーザーのプロフィールへ遷移
  │       │
  │       ▼
  │   そのユーザーの本棚を閲覧
  │       │
  └─ 新しい書籍を発見
```
