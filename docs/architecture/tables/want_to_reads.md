# want_to_reads

## 概要

ユーザーの「読みたい」リストを管理するテーブル。
他ユーザーの本棚投稿へのいいね操作、または書籍詳細・検索結果からの直接追加で登録される。
読みたいリストはユーザー本人のみ閲覧可能。

## カラム定義

| カラム名 | 型 | NULL | 制約 | 説明 |
|---|---|---|---|---|
| id | bigint | NO | PK | |
| user_id | bigint | NO | FK → users | 登録したユーザー |
| book_id | bigint | NO | FK → books | 読みたい書籍 |
| created_at | datetime | NO | | |

## インデックス

| インデックス | カラム | 用途 |
|---|---|---|
| PRIMARY KEY | id | |
| UNIQUE | (user_id, book_id) | 同じ書籍の重複登録防止 |
| INDEX | user_id | 読みたいリスト取得 |
| INDEX | book_id | 書籍ごとの読みたい数集計 |

## リレーション

| 関連テーブル | 種別 | 説明 |
|---|---|---|
| users | N:1 | 登録したユーザー |
| books | N:1 | 対象書籍 |

## 備考

- 読みたいリストは登録日時の降順（created_at DESC）で表示します
- 読みたい → 読了への遷移は、読みたいリストから投稿画面に遷移して本棚追加を行う操作で実現します（自動遷移ではなくユーザー操作）
